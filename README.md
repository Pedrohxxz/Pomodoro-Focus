# Pomodoro Focus

App de Pomodoro com alarmes personalizáveis (HTML, CSS e JavaScript puros, sem dependências).

## Estrutura

```
pomodoro/
├── index.html      # estrutura da página
├── css/style.css   # estilos e tema (preto, branco, vermelho, roxo)
└── js/script.js    # timer, áudio e configurações
```

## Como usar

Abra o `index.html` no navegador (duplo clique). Não precisa instalar nada.

## Recursos

- Foco de 20 min e descanso de 5 min (ajustáveis)
- Alarme personalizado para o início do descanso e para a volta ao foco
- Sons e tempos salvos no navegador (IndexedDB e localStorage)
